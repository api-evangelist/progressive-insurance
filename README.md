# Progressive Insurance (progressive-insurance)

One of the largest auto insurance providers in the United States offering personal auto, motorcycle, boat, RV, home, renters, and commercial insurance. Progressive is known for its direct-to-consumer model, the independent-agent channel via ForAgents, comparative rate quoting, and the Snapshot usage-based insurance program. Progressive does not publish a public developer API - third-party connectivity with comparative raters, agency management systems, and telematics providers is handled via private B2B integrations.
